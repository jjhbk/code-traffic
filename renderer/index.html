Secure browser connection

Google will open in your browser. Signal Box never asks you to paste keys or passwords here.

Create this once in Google Cloud under OAuth clients → Desktop app. The same client can be reused for Calendar and Drive.

Some Google desktop clients require this during token exchange. Signal Box stores it only in the OS credential store.

How do I create this?
  1. Create a Google Cloud project. Open Google Cloud
  2. Open APIs & Services → Library and enable Gmail API.
  3. Open Google Auth Platform → Branding and configure the app name and support email.
  4. Under Audience, choose External and add your own Google account as a test user.
  5. Under Clients, create an OAuth client → Desktop app. Copy only the client ID here.

Google may issue a client secret for desktop apps. Signal Box keeps the secret and refresh token in the operating system credential store.
